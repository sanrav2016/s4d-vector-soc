# SSM Accelerator

Edge AI SoC with PicoRV32 RISC V core and State Space Model (SSM) coprocessor

### Summary
WiP

### Dependencies
- riscv64-unknown-elf-gcc
- python3
- iverilog
- gtkwave (optional)

### Usage
```
> git clone https://github.com/sanrav2016/ssm-accelerator.git
> cd ssm-accelerator
> make
> make wave     # view waveform
> make clean    # delete .tmp dir
```
